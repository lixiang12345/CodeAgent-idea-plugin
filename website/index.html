Modes

一个面板，三种协作方式

从只读分析到全自动改代码，信任级别由你决定，随时切换。

AGENT

Agent 模式

  • 自主规划并执行多轮工具循环
  • 读写文件、运行终端、打开编辑器
  • 所有变更走审批卡，可随时取消
  • 任务清单实时更新执行进度
CHAT

Chat 模式

  • 基于仓库上下文的代码协作对话
  • 自动检索相关文件与符号
  • 适合方案讨论、代码讲解与评审
  • 与 Agent 共享线程与历史
ASK

Ask 模式

  • 严格只读，不产生任何修改
  • 快速理解陌生代码与调用链
  • 安全地面向生产仓库提问
  • 随时升级为 Chat 或 Agent 继续
Features

看得见过程，管得住结果

CodeAgent 不是黑盒：智能体做的每一件事都以工具卡片的形式流式呈现，重要动作在执行前等待你的批准。

每一步都看得见的智能体循环

后端驱动的有界多轮工具循环，把检索、读文件、搜索、编辑、建文件、跑终端的全过程实时流回面板。

  • Token 级流式响应，工具调用边组装边呈现
  • 工具时间线覆盖 ContextEngine 检索、Grep、编辑、终端、Mermaid 图表等
  • 任务清单随线程持久化，进度一目了然
  • 运行中输入的消息进入会话级 FIFO 队列，依序派发

修改先审批，命令要点头

文件写入与终端命令默认进入审批流，审批卡内嵌在对话里，看清楚再放行；Ask 模式则从根上保持只读。

  • 文件变更与命令执行弹出内联审批卡，可批准或跳过
  • 逐工具权限规则，拒绝规则优先于放行
  • 运行随时取消，失败回合支持重试
  • 等待审批的运行有明确状态提示，不会悄悄执行

原生 Diff 审阅，检查点级回滚

Agent Edits 汇总一次运行的全部文件改动，复用 IntelliJ 原生 Diff 组件审阅；不满意的编辑逐条撤销，或一键全收 / 全弃。

  • IntelliJ 原生 Diff，与手工 Code Review 同一套体验
  • 检查点快照可恢复到运行前的文件状态
  • 逐文件 Diff / Undo，支持 Keep all 与 Discard all
  • 文件工具的每次编辑都有受保护的回滚路径

线程、任务与长会话导航

每个项目的对话按线程组织，支持置顶、未读计数与 Markdown 导入导出；超长会话可以按请求逐段跳转，新消息不会把你拽离正在读的历史。

  • 线程置顶、确认删除、未读回复计数持久保存
  • 活动运行、待审批、失败状态在列表中直接可见
  • 请求级导航 + 跳到最新，读历史与追进度两不误
  • 对话与任务清单支持 Markdown 导入 / 导出
Capabilities

完整的工程化能力面

从上下文检索到扩展机制，CodeAgent 把智能体需要的每一层都做成了可配置、可审计的真实能力。

ContextEngine 检索

词法、符号、路径、代码图、Git 溯源五类检索纯本地运行，无需模型；语义检索为显式可选项。

Rules 与 Skills

仓库规则常开生效，技能按任务显式选择；JVM 负责校验，后端负责组装进提示词。

MCP 与 ACP

接入 MCP 服务器扩展工具面，支持 OAuth 元数据发现与动态客户端注册，兼容原生配置形态。

声明式插件

插件是有界 JSON 清单而非可执行代码：版本、完整性、能力授予逐项校验后才激活。

BYOK 自带密钥

Anthropic、OpenAI、AWS Bedrock 密钥可自带，存入 JetBrains Password Safe,随时清除。

托管进程会话

长时命令交给项目级进程会话：启动、读写、等待、终止全套操作，输出封顶，变更需审批。

Git 与 Image Canvas

Git 页读取真实索引与工作树，提交前必须确认；Image Canvas 预览项目图片并附加到对话。

云端协作面

只读会话分享链接、运营通知与订阅额度告警；后端未配置时如实显示不可用，绝不伪造成功。

Security & Trust

为生产仓库设计的信任模型

智能体的能力越强，边界就越重要。CodeAgent 把「可控」写进了架构，而不是写在宣传语里。

凭据不出安全域

OIDC 访问 / 刷新令牌存入 JetBrains Password Safe,插件设置里只保留过期元数据；模型与集成凭据始终留在部署后端，IDE 侧一份都没有。

数据边界清晰

ContextEngine 的索引完全本地；只有当前运行选定的仓库上下文、规则、技能与消息会发送到你配置的后端。发给谁、发什么，始终明确。

变更可控、可回

文件编辑逐条带回滚路径，检查点可恢复运行前状态；终端副作用不妄称能自动回滚 —— 能保证的才承诺，这是产品原则。

状态真实上报

Settings 显示的是真实的健康检查、模型与工具发现结果 —— 配置了 URL 不等于后端在线；未配置的云端能力明确显示不可用，不伪装成功。
